# 08 — Карточка слова

**Зависит от:** 04, 05, 07
**Результат:** экран `/words/:wordId` со значениями, формами и раздельным прогрессом.

---

## Требования: FR-40 … FR-48

## Шаги

### 1. Шапка

```text
mieć
VERB · A1 · частота #5
иметь
```

Для существительного дополнительно — род (`dominantGender` из парадигмы, задача 02).
У 202 существительных род в формах неоднороден — показывать доминирующий, не выдумывать один.

### 2. Значения

Все senses списком, основное первым. `gloss_en` — вторичным текстом, мелко:
он полезен для снятия неоднозначности, но пользователь учит русский↔польский.

### 3. Формы слова — свёрнуто по умолчанию

**Критично** (FR-42, app-design §4): блок закрыт, пока пользователь сам не раскроет.
Иначе экран превращается в шпаргалку и убивает active recall.

Таблицы (задача 04 отдаёт готовые структуры):

- NOUN: `падеж × число`, порядок падежей канонический — M. D. C. B. N. Ms. W.
- VERB: по временам/наклонениям; аналитические формы (`będę robić`) помечены;
  прошедшее время — с разбивкой по родам.
- ADJ: `падеж × род`, переключатель `singular / plural`, отдельный блок степеней сравнения.
- ADV: только степени сравнения.

Слот с несколькими формами (`aborcji` / `aborcyj`) показывает обе.

Для 14 слов без парадигмы блок не рендерится вовсе.

### 4. Раздельный прогресс

```text
Слово       ██████████ 100%
Формы       ███████░░░  72%
```

При раскрытии — детализация по измерениям (FR-47):

```text
Mianownik    ✓
Dopełniacz   ✓
Narzędnik    72%
Miejscownik  44%
Wołacz       новое
Liczba mnoga 37%
```

Значения вычисляются `aggregateByDimension` (задача 03), в БД не хранятся.

### 5. Действия

`Знаю` — перевести vocab-навыки в состояние `known` (см. задачу 16, та же логика, что и свайп).
`Учить` — запустить сессию только по этому слову.
`Сбросить прогресс` — с подтверждением, удаляет навыки слова и пересчитывает `wordProgress`.

### 6. Загрузка

Парадигма грузится лениво — при раскрытии блока форм, не при открытии экрана.
Один шард ~15 КБ gz, но незачем тянуть его, если пользователь смотрит только перевод.
