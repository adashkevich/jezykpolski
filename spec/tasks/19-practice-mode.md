# 19 — Режим Practice и экран настройки тренировки

**Зависит от:** 18
**Результат:** пользователь может вручную задать, что тренировать.

---

## Требования: FR-111 … FR-114, FR-11 (разделение Learn/Practice)

## Принцип (app-design §24)

| | Learn | Practice |
|---|---|---|
| Что тренируем | решает алгоритм | решает пользователь |
| Вход | «Продолжить обучение» | экран настройки |
| Влияние на SRS | полное | демпфированное (задача 11, правило 2) |
| Влияние на статистику | полное | полное |

Это UX-разделение, а не техническая деталь: без него пользователь либо лишён контроля,
либо ломает себе планирование ручными прогонами.

---

## Шаги

### 1. Единый компонент настройки

`features/training-setup/` — один компонент, параметризуемый разделом (FR-113).
Не писать три похожих экрана для существительных, глаголов и прилагательных.

```text
Тренировка существительных

Уровень        До B1
Статус         Новые + изучаемые
Частотность    Top 3000

── Что тренировать ──
☑ Перевод
☑ Единственное число
☑ Множественное число

── Падежи ──
☑ Mianownik   ☑ Dopełniacz   ☐ Celownik
☐ Biernik     ☐ Narzędnik    ☐ Miejscownik
☐ Wołacz

── Тип задания ──
☑ Выбор ответа   ☑ Ввод ответа

20 заданий

[ Начать ]
```

Конфигурация раздела — декларативная:

```ts
interface TrainingDimensionGroup {
  key: string;
  label: string;
  options: Array<{ value: string; label: string; labelRu: string; defaultOn: boolean }>;
}
```

Для существительных — падежи и числа; для глаголов — времена, лица, числа; для прилагательных —
падежи, роды, числа, степени. Один компонент, три конфигурации.

### 2. `build-practice-queue.ts`

```ts
buildPracticeQueue(config: PracticeConfig, ctx): QueuePlan
```

Отличия от learn-очереди:
- фильтрация по явно выбранным измерениям, а не по `due`;
- навыки могут быть не просрочены — это нормально;
- новые навыки материализуются по мере показа (та же `ensureSkill`).

Если под фильтр не попало ни одного слова — показать это **до** нажатия «Начать»,
а не пустой сессией после.

### 3. Предпросмотр объёма

Под настройками показывать «Найдено 412 слов, 2 890 форм». Пользователь должен понимать,
насколько узкий фильтр он задал.

### 4. Сохранение пресетов

Последняя конфигурация сохраняется в `settings` и предлагается при следующем входе.
Именованные пресеты — опционально, не в MVP.

### 5. Вход из списка слов

Кнопка «Учить» в списке (задача 07, п.7) открывает этот экран с предзаполненными
текущими фильтрами списка.

## Acceptance

- [ ] Один компонент обслуживает существительные, глаголы и прилагательные
- [ ] Выбор падежей/времён влияет на состав очереди
- [ ] Practice-сессия обновляет SRS слабее, чем learn (проверяется на одинаковом наборе ответов)
- [ ] Practice-сессия полностью учитывается в статистике точности
- [ ] Предпросмотр объёма совпадает с реальным размером очереди
- [ ] Пустой результат фильтра сообщается до старта сессии
- [ ] Конфигурация восстанавливается при следующем входе
- [ ] Вход из списка слов подставляет текущие фильтры
- [ ] Экран юзабелен на 320px; чекбоксы имеют тач-таргет ≥ 44px
