# 15 — Главный экран

**Зависит от:** 11, 13
**Результат:** экран `/`, отвечающий на вопрос «что мне сейчас делать».

---

## Требования: FR-10 … FR-14

## Шаги

### 1. Структура

```text
Dzisiaj

Повторить
34 слова готовы к повторению
[ Продолжить обучение ]        ← единственный основной CTA

────────────────

Слова            1 348 изучается · 782 выучено   [ Открыть ]
Существительные  326 / 1 240
Глаголы          284 / 1 050
Прилагательные   119 / 680

────────────────

Сегодня
42 повторения · 18 новых слов · 87% правильных
```

### 2. Один CTA (FR-14)

На экране **одна** заметная кнопка. Всё остальное — вторичные ссылки.
Главная не должна предлагать выбор между пятью действиями: она отвечает на вопрос
«что делать сейчас», а не «что тут вообще есть».

### 3. Источники данных

| Блок | Откуда |
|---|---|
| «Повторить N» | `countDue(now)` |
| «изучается / выучено» по разделу | агрегация `wordProgress` по статусу и части речи |
| «Сегодня» | `dailyStats` за текущую дату |

Все — через `useLiveQuery`, обновляются сами после сессии.

**Производительность:** агрегация по 7998 записям `wordProgress` на каждый рендер главной —
дорого. Считать через `db.wordProgress.where('status').equals(...).count()` (по индексу),
а не загрузкой всех записей в память.

### 4. Пустые состояния

- Нет ни одного изученного слова → CTA «Начать обучение», текст-онбординг в одну строку.
- Нет повторений на сегодня → CTA переключается на «Учить новые слова», счётчик не показывается
  как «0 готовы к повторению» (это выглядит как ошибка).

### 5. Отдельного экрана «Повторение» нет

По app-design §1 — в MVP это кнопка на главной, а не пятый раздел навигации.

## Acceptance

- [ ] «Повторить N» совпадает с реальным числом просроченных навыков
- [ ] «Продолжить обучение» запускает сессию без промежуточного экрана настройки
- [ ] Счётчики разделов совпадают с фильтром по статусу в списке слов
- [ ] Блок «Сегодня» обновляется сразу после завершения сессии (без перезагрузки)
- [ ] На экране ровно один основной CTA
- [ ] Пустое состояние (свежая установка) выглядит осмысленно
- [ ] Нет повторений → CTA меняется, не показывается «0 готовы к повторению»
- [ ] Подсчёты идут через индексы, не через загрузку всех `wordProgress` в память
- [ ] Вёрстка корректна на 320px
