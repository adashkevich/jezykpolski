# 50 — Карточка слова: значения с пояснением, примером и уровнем

**Зависит от:** 47, 49
**Результат:** на карточке слова каждое значение показывает переводы, польское пояснение
(`gloss_pl`), пример (`example_pl`) и свой уровень; primary-значение помечено как изучаемое, прочие —
«позже». После ответа в упражнении фидбэк показывает пример primary-значения.

---

## Зачем

`SensesList` сейчас печатает `sense.ru` и `sense.en`; `en` в v2 нет, зато появились пояснение и
пример — самое полезное из переработки словаря. А раз учим только primary (задача 49), пользователь
должен видеть, какое из значений сейчас в работе, иначе «прочие» значения на карточке выглядят как
то, что он уже должен знать.

## 1. `useSenses` / `SensesList`

- `useSenses` дополнительно запрашивает `getSenseDetails(wordId)` (задача 47 §4). Детали грузятся
  отдельно: переводы показываются сразу из уже прогретого шарда, пояснение и пример дорисовываются,
  когда придёт шард деталей. Ошибка загрузки деталей не ломает список — только скрывает
  пояснения (без сообщения об ошибке: офлайн без прогретого шарда — штатная ситуация).
- `key` элемента — `sense.id`, а не индекс.
- Разметка значения:
  ```
  1. закон, право                         [A2] [изучаем]
     ogół przepisów obowiązujących w państwie
     «Prawo zabrania palenia w restauracjach.»
  ```
  - переводы — переводы активного профиля (задача 51; до неё — `ru`);
  - пояснение — `text-body-sm text-muted-foreground`, `lang="pl"`;
  - пример — курсивом, `lang="pl"`;
  - бейдж уровня значения (уровень активного профиля); бейдж «изучаем» — у primary, у прочих
    приглушённый «позже». Если значение одно — бейджи «изучаем/позже» не показываются.
- Primary всегда первым (порядок шарда, задача 47 §3).

## 2. Пример в фидбэке упражнения

`ExerciseFeedback` для vocab-упражнений (`choice`/`input`/`self-assess`, оба направления) после
ответа показывает `example_pl` primary-значения строкой под правильным ответом. Источник —
`SessionContentContext`: детали шарда грузятся в том же `prepare(wordId)`, что и переводы, но
**не блокируют** показ вопроса — если шард деталей не успел, пример просто не выводится.
В matching и грамматических упражнениях пример не выводится.

Пример не должен подсказывать ответ **до** ответа: выводится только в состоянии фидбэка.

## 3. Список слов

`WordRow` — без изменений (`primaryRu`). Поиск по русскому — по-прежнему по `primaryRu`; поиск по
переводам прочих значений не добавляется (индекс не несёт их, а грузить шарды для поиска дорого).
