# 25 — Офлайн, кэширование, UX обновления

**Зависит от:** 06, 02
**Результат:** учебный цикл полностью работает без сети; обновление приложения не ломает сессию.

---

## Требования: NFR-01 … NFR-03, NFR-17

## Шаги

### 1. Precache

```text
app shell (HTML/JS/CSS)
иконки
content/manifest.json
content/index.json           112 КБ gz
content/senses/*.json        376 КБ gz
```

Бюджет — 500 КБ gz (NFR-05). Если `senses` не помещаются вместе с бандлом,
перевести их в runtime-кэш с прогревом при первом запуске, а precache оставить
только `index.json`. Решение принять по факту замера, записать в журнал `00-progress.md`.

### 2. Runtime cache

`content/paradigms/*.json` — `CacheFirst`:

```text
cacheName: `paradigms-${contentVersion}`
maxEntries: 64
maxAgeSeconds: 31536000
```

`contentVersion` в имени кэша даёт бесплатную инвалидацию при пересборке контента.
Старые кэши удаляются в `activate`.

### 3. Навигация офлайн

SPA-fallback на `index.html` в service worker: прямой заход на `/words/kobieta%7CNOUN`
в офлайне должен открывать приложение, а не ошибку сети.

### 4. Индикатор офлайна

`useOnlineStatus` + ненавязчивая плашка. Важно: **офлайн не должен блокировать ничего**
из учебного цикла. Плашка нужна только чтобы объяснить, почему не грузятся формы
незагруженного слова.

### 5. UX обновления (NFR-17)

`registerType: 'prompt'`:

```text
Доступна новая версия
[ Обновить ]  [ Позже ]
```

**Если активна сессия — предложение откладывается** до её завершения. Перезагрузка страницы
посреди упражнения выглядит как потеря данных, даже если прогресс сохранён.

### 6. Проверка квоты

`navigator.storage.estimate()` — если места мало, предупредить до префетча шардов.
`navigator.storage.persist()` — запрашивать после того, как пользователь реально начал учиться
(запрос на пустом приложении пользователи отклоняют).

### 7. Граница ошибок

Сбой загрузки шарда парадигм в офлайне — это ожидаемое состояние, а не краш:
показать «Формы недоступны офлайн» с предложением включить префетч в настройках.
