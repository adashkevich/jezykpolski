# 14 — Результаты сессии и режим ошибок

**Зависит от:** 13
**Результат:** экран `/session/result` и разбор ошибок.

---

## Требования: FR-100, FR-101, FR-102, FR-103

## Шаги

### 1. Экран результатов

```text
Готово

18 / 20
90%

Новые слова       6
Повторено         14

Сложнее всего
  Miejscownik     61%
  Dopełniacz      84%

Ошибки
  człowiek · Miejscownik
  człowieka → człowieku

  kobieta · Celownik
  kobiety → kobiecie

[ Разобрать ошибки ]   [ Закончить ]
```

Формат ошибки — `что ввёл → что ожидалось`. Именно это и делает `answerGiven` в `reviewLogs`
(FR-100) осмысленным: без сохранённого ответа пользователя разбор невозможен.

Блок «Сложнее всего» строится группировкой логов сессии по измерению навыка.
Для чисто vocabulary-сессии он группируется по части речи и уровню.

### 2. Режим «Повторить только ошибки»

Новая сессия с `mode: 'mistakes'`, очередь = навыки, на которых были ошибки.

**Ключевое ограничение (FR-103):** SRS-состояние в этом режиме не обновляется вовсе,
либо обновляется только при ухудшении. Пользователь только что видел правильный ответ —
успех здесь ничего не доказывает. Всё пишется в `reviewLogs` с `srsApplied: false`,
влияет на статистику точности, но не на планирование.

### 3. Запись сессии

При завершении обновляется `SessionRecord`: `endedAt`, число заданий, верных, новых слов,
и `dailyStats` за текущую дату (локальная таймзона).

### 4. Пустой результат

Если сессия прервана после нуля ответов — не показывать экран результатов, вернуть на главную.

---

## Acceptance

- [ ] Счёт и процент соответствуют реальным логам сессии
- [ ] Каждая ошибка показана как `введено → ожидалось`
- [ ] Блок «Сложнее всего» группирует по измерениям и сортирует по возрастанию точности
- [ ] «Разобрать ошибки» запускает сессию только из ошибочных навыков
- [ ] В режиме `mistakes` `SkillRecord` не улучшается ни при одном рейтинге
- [ ] Логи режима `mistakes` имеют `srsApplied: false`
- [ ] `dailyStats` за сегодня обновляется корректно, включая случай сессии около полуночи
- [ ] Сессия с нулём ответов не создаёт мусорную запись в `sessions`
