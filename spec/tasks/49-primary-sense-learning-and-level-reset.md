# 49 — Учим только primary-значение; возврат на A1 после смены словаря

**Зависит от:** 38, 47, 48
**Результат:** слово вводится в обучение по уровню своего primary-значения и спрашивается только
по нему. После перехода на словарь v2 гейт уровней один раз возвращается на A1 и дальше идёт по
обычным правилам задачи 38: пока в A1 есть неначатые слова — новые слова берутся оттуда.

---

## Зачем

Запрос пользователя: «для некоторых слов мог измениться уровень, поэтому его нужно reset в A1 и
там уже смотреть, есть ли подходящие слова. Пока нужно учить только primary значения».

После задачи 47 в A1 по primary-значению 1178 слов против 386 раньше: ~790 слов, которые раньше
были A2–B2 и пользователем ещё не начаты, теперь A1. Гейт задачи 38 считается «на лету» из
`unstartedByLevel` и `startLevel`, поэтому сам по себе он уже вернётся на A1, **если** `startLevel`
пользователя — A1. Если пользователь когда-то поднял `startLevel` в настройках (например, до A2),
A1 для него закрыт навсегда — это и надо сбросить.

## 1. Сброс уровня

`StartupMigrations.tsx`: шаг `runOnce('content-v2-level-reset', …)` **после** шага задачи 48:

- `settings.newWordsStartLevel` → `'A1'` (`NEW_WORDS_START_LEVEL_DEFAULT`); если значение уже A1 —
  запись не трогается;
- в `meta` пишется `contentV2Notice = { previousStartLevel, at }` для баннера ниже.

Прогресс не трогается: начатые слова остаются начатыми и приходят на повторение по расписанию
независимо от уровня (задача 38, «Где ничего не меняется»). Слово, которое пользователь уже учил на
B1 и которое стало A1, — просто уже начатое слово A1; в `unstartedByLevel.A1` оно не входит.

**Баннер на главной (один раз):** «Словарь обновлён: уровни слов пересчитаны. Новые слова снова
идут с A1 — осталось N». Закрывается крестиком (удаляет `meta.contentV2Notice`). Если
`previousStartLevel` был выше A1 — дописать «Начальный уровень сброшен с B1 на A1, изменить можно
в настройках».

`/stats` (`LevelProgressCard`) перестраивается сам: счётчики по уровням берутся из индекса.

## 2. Только primary-значение

Навыки остаются на уровне слова (`<wordId>::vocab:…`) — неявно это навыки primary-значения.
Переход на навыки по значениям (`<wordId>#<senseId>::…`) — отдельная будущая задача, сейчас не
делается.

| Место | Сейчас | Должно быть |
|---|---|---|
| Уровень слова для гейта, фильтров, `/stats` | `introduced_at` слова | уровень primary (уже так после задачи 47 — проверить, что нигде не читается иной источник) |
| Подсказка RU→PL, вопрос PL→RU (правильный вариант) | `primaryRu` | без изменений — `primaryRu` теперь = первый перевод primary-значения (задача 47) |
| Принимаемые ответы PL→RU (`getAllTranslations`) | переводы всех значений | **без изменений**: назвать верное, но не primary значение — не ошибка |
| Дистракторы: исключение пересечений | все значения | без изменений |
| `MatchingExercise` | `primaryRu` | без изменений |
| Прочие значения на карточке слова | показаны наравне | помечены «позже» (задача 50) |

Проверить `primary` не по позиции: `content/senses.ts`, `distractors.ts#resolveTranslations` и
все места, где берётся `senses[0]`, должны искать `sense.primary` (после задачи 47 шард и так
кладёт primary первым, но не полагаться на это молча — `ripwire . --uses=getSenses`).

## Реализация — где отступает от текста выше

- **Шаг** — отдельный файл `src/db/repositories/content-v2-level-reset.repository.ts`
  (`runContentV2LevelReset`, по образцу `word-id-renames.repository.ts`), последним в
  `STARTUP_MIGRATIONS`. Сброс уровня и запись `meta.contentV2Notice` — одна `rw`-транзакция по
  `settings` + `meta` + `skills`: повторный запуск после обрыва не должен прочитать уже сброшенный
  A1 и потерять `previousStartLevel`.
- **Уведомление пишется только пользователю с прогрессом** (`hasAnySkill()`): для пустого профиля
  «словарь обновлён» ничего не сообщает. Сброс уровня от этого не зависит — `newWordsStartLevel`
  возвращается на A1, если он не A1. Для пользователя, который и так на A1, уведомление пишется
  (баннер — одно предложение). `at` — `Date.now()`; число «осталось N» не хранится.
- **Баннер** — `src/features/content-update/components/ContentV2Notice.tsx` над героем главной
  (`role="status"`), живой запрос `useContentV2Notice` (`meta`-ключ `contentV2Notice`), крестик
  «Закрыть» вызывает `clearContentV2Notice()`. N — `unstartedByLevel[currentLevel]` из
  `useLevelGate`, то есть то же число, что в строке «Сейчас изучаем» под кнопкой:
  - `currentLevel = A1` — «Словарь обновлён: уровни слов пересчитаны. Новые слова снова идут с A1 —
    осталось N» (текст спеки дословно);
  - A1 уже начат целиком — «… Новые слова идут с A2 — осталось N» (уровень, который сообщает гейт);
  - в открытом диапазоне неначатых слов нет — только первое предложение;
  - `previousStartLevel` выше A1 — вторая строка «Начальный уровень сброшен с B1 на A1, изменить
    можно в настройках».
- **`primary` по флагу, не по позиции.** `senses[0]` нигде не читался; позицию «primary первым»
  предполагали только комментарии. `content/senses.ts#primaryFirst` ставит помеченное значение
  первым (без пометки порядок не меняется), `getSenses` его применяет; `translationsPrimaryFirst` —
  общая для `getAllTranslations` и `distractors.ts#resolveTranslations` (до этого там были два
  одинаковых цикла). Принимаемые ответы PL→RU, исключение пересечений и `MatchingExercise` — без
  изменений, как в таблице §2.
- **Источник уровня** проверен по `src/`: гейт (`computeLevelPoolCounts`, `orderNewWordCandidates`),
  фильтры (`content/query.ts`), `/stats` и главная (`stats.repository.ts`,
  `getWordProgressSummary`), дистракторы — только `WordIndexEntry.level` из индекса;
  `introduced_at` читает лишь схема сборки (`content.schema.ts`).
- **Не сделано (вне текста задачи):** бэкап, снятый до обновления, несёт старый
  `newWordsStartLevel`; при импорте после запуска шага он вернёт высокий уровень без уведомления.
