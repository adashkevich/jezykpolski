# 24 — Настройки, экспорт/импорт, сброс

**Зависит от:** 05
**Результат:** экран `/settings` и надёжный локальный бэкап.

---

## Требования: FR-130 … FR-135, NFR-16

## Зачем это важнее, чем кажется

Аккаунта и облака нет (по требованию). Единственная защита прогресса пользователя от
очистки данных браузера — экспорт. Эта задача не «полировка», а страховка данных.

---

## Шаги

### 1. Настройки

```text
Обучение
  Новых слов в день          10
  Заданий в сессии           20
  Подсказка в морфологии     лемма / перевод / случайно
  Тип задания по умолчанию   выбор + ввод

Интерфейс
  Тема                       системная / светлая / тёмная

Данные
  Скачать все формы для офлайна   [ вкл ]      (64 шарда, ~1 МБ)
  Экспорт прогресса               [ Скачать ]
  Импорт прогресса                [ Выбрать файл ]
  Сбросить учебные данные         [ Сбросить ]

О приложении
  Версия приложения    0.1.0
  Версия контента      a1b2c3d4e5f6
  Слов в базе          7 998
```

### 2. Экспорт

```json
{
  "schemaVersion": 1,
  "exportedAt": "2026-09-01T12:00:00.000Z",
  "contentVersion": "a1b2c3d4e5f6",
  "skills": [],
  "reviewLogs": [],
  "sessions": [],
  "dailyStats": [],
  "settings": {}
}
```

`wordProgress` **не экспортируется** — это денормализация, восстанавливается пересчётом
(`recomputeAll`). Это уменьшает файл и исключает рассинхрон.

Скачивание через Blob + `URL.createObjectURL`.
При большом числе `reviewLogs` (десятки тысяч) — предупредить о размере файла.

### 3. Импорт

Строгий порядок, ни шага меньше:

```text
1. прочитать файл
2. валидировать Zod-схемой (NFR-16: никогда не доверять структуре импорта)
3. проверить schemaVersion; неизвестная версия → отказ с понятным сообщением
4. показать сводку: «Будет импортировано 1 240 навыков, 8 900 записей истории.
   Текущий прогресс будет заменён.»
5. подтверждение пользователя
6. транзакционная замена данных
7. recomputeAll() — восстановить wordProgress
8. отчёт о результате
```

Расхождение `contentVersion` — **предупреждение, не ошибка**: `wordId` стабилен, привязка
не ломается. Навыки, ссылающиеся на исчезнувшие слова, пропускаются с указанием их числа.

### 4. Сброс

Двухшаговое подтверждение с вводом подтверждающего слова или явным чекбоксом.
Предложить сначала сделать экспорт. Очищает все таблицы, кроме `meta.contentVersion`.

### 5. Офлайн-префетч

Переключатель «Скачать все формы для офлайна» загружает все 64 шарда парадигм
в Cache Storage с индикатором прогресса. Отменяемо. Без него формы работают офлайн
только для уже просмотренных слов.

---

## Acceptance

- [ ] Экспорт → полный сброс → импорт восстанавливает прогресс идентично (проверить сравнением агрегатов)
- [ ] Импорт битого JSON даёт понятную ошибку и **не трогает БД**
- [ ] Импорт с неизвестным `schemaVersion` отклоняется
- [ ] Импорт с другим `contentVersion` проходит с предупреждением
- [ ] Навыки несуществующих слов пропускаются, их число показано в отчёте
- [ ] `wordProgress` корректно пересчитывается после импорта
- [ ] Сброс требует двух подтверждений и предлагает экспорт
- [ ] Префетч шардов показывает прогресс и отменяется
- [ ] После префетча формы любого слова открываются в офлайне
- [ ] Все настройки применяются немедленно и переживают перезагрузку
