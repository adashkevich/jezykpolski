# 51 — Языковой профиль: русский / + белорусский / + украинский

**Зависит от:** 47, 49, 50
**Результат:** в настройках выбирается профиль «Знаю русский», «Знаю русский и белорусский» или
«Знаю русский и украинский». Профиль определяет, по какой колонке уровней (`ru`/`by`/`ua`) идут
гейт уровней, фильтры и статистика, и какие переводы дополнительно видны на карточке слова.

---

## Зачем

Словарь v2 оценивает уровень каждого значения для трёх профилей и несёт переводы на белорусский и
украинский. Для носителя украинского или белорусского часть польских слов прозрачнее, чем для
носителя только русского, — у 235 значений уровень `ua` и у 219 значений уровень `by` отличаются от
`ru`. Без выбора профиля эти данные лежат мёртвым грузом.

Задача независима от 46–50 по поведению: до неё приложение работает в профиле `ru`. Её можно
отложить без ущерба для перехода на словарь v2.

## 1. Настройка

- `learning/session/lang-profile.ts`: `LANG_PROFILE_SETTING_KEY = 'langProfile'`, тип
  `LangProfile = 'ru' | 'by' | 'ua'`, по умолчанию `'ru'`.
- `LearningSettingsSection`: селект «Языки, которые я знаю» над «Начальным уровнем».
- Интерфейс приложения остаётся русским во всех профилях; вопросы упражнений RU↔PL тоже
  (переводы `translation_ru` — единственный язык, на котором есть все интерфейсные тексты и
  `primaryRu` для списка).

## 2. Уровни

- `index-store.ts`: `WordIndexEntry.level` — уровень активного профиля из `levels` (задача 47 §4).
  При смене профиля пересобираются `byLevel` и всё, что от него зависит (`ContentProvider`
  подписан на настройку; объект индекса меняет идентичность → `useMemo`-потребители
  пересчитываются).
- Смена профиля **не** сбрасывает `startLevel` и прогресс; гейт задачи 38 пересчитывается сам.
  Если в новом профиле текущий уровень сменился, на главной это видно сразу.

## 3. Переводы

- Карточка слова (задача 50): под переводами на русский строкой ниже — переводы профиля
  (`by`/`ua`), с пометкой языка («бел.»/«укр.») и `lang="be"`/`lang="uk"`. В профиле `ru` строки нет.
- Фидбэк упражнения — то же, одной строкой под правильным ответом.
- В ответах упражнений PL→RU переводы `by`/`ua` **не** принимаются: варианты и проверка — по
  `translation_ru` (иначе раскладка клавиатуры и сравнение строк усложняются без явной пользы).

## 4. Бэкап

`langProfile` — обычная настройка, попадает в экспорт автоматически (`settings` выгружается
целиком).
