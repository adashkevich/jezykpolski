# 17 — Раздел существительных и таблица склонения

**Зависит от:** 08, 13
**Результат:** режим «Существительные» с раздельным прогрессом по падежам.

---

## Требования: FR-02, FR-43, FR-46, FR-47

## Данные

3685 существительных, 3676 парадигм, в среднем 15.1 форм (максимум 56).
Падежи: nominative, genitive, dative, accusative, instrumental, locative, vocative.
Числа: singular, plural.
Роды: feminine, masculine_personal, masculine_inanimate, masculine_animate, neuter.

**У 202 существительных в одной парадигме встречается больше одного рода** — это не ошибка данных,
а особенность разметки. Показывать доминирующий род в шапке, но не терять родовую метку на формах.

---

## Шаги

### 1. Экран

Это не отдельная страница, а режим `/words` с `pos=NOUN` (см. задачу 07, п.5) —
строка списка получает вторую шкалу «Склонение».

```text
człowiek
человек · A1
Значение    ✓
Склонение   72%
```

### 2. Навыки существительного

`enumerateSkills` (задача 03) порождает `noun:<number>:<case>` **только для слотов,
которые реально есть в парадигме**. Декартово произведение 2×7 даст несуществующие слоты
у слов без множественного числа.

### 3. Прогресс по падежам

`aggregateByDimension` группирует навыки слова по падежу и по числу:

```text
Mianownik     ✓
Dopełniacz    ✓
Celownik      ✓
Biernik       ✓
Narzędnik     72%
Miejscownik   44%
Wołacz        новое

Liczba pojedyncza  88%
Liczba mnoga       37%
```

Порядок падежей — канонический из `dimensions.ts`, не алфавитный.

### 4. Таблица склонения в карточке слова

`case × number`, свёрнута по умолчанию (FR-42).
Слот с несколькими формами показывает обе (`aborcji` / `aborcyj`).
Пустой слот (формы нет в данных) — прочерк, не пустая ячейка.

Каждая ячейка кликабельна: показывает состояние навыка и позволяет запустить точечную тренировку.

### 5. Терминология

Польские названия падежей — основные, русские — вспомогательные:

```text
Dopełniacz    (родительный)
Miejscownik   (предложный)
```

Пользователь учит польскую грамматическую терминологию; она понадобится ему в учебниках.

### 6. Wołacz

Звательный падеж употребляется редко и обычно не входит в базовый курс.
По умолчанию **выключен** в настройке тренировки (см. app-design §9), но доступен в таблице
и включаем вручную.
