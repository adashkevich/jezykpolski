# 10 — Генератор дистракторов

**Зависит от:** 04, 09
**Результат:** осмысленные неправильные варианты вместо случайных.

---

## Требования: FR-90 … FR-94

## Зачем отдельная задача

app-design §19: у нас 7998 реальных слов, и это преимущество. Случайные дистракторы
(`арбуз / синий / бежать` для `wiedzieć`) делают вопрос тривиальным и завышают оценку знания.

---

## Шаги

### 1. Vocabulary-дистракторы

```ts
pickVocabDistractors(target: WordIndexEntry, direction: Direction, n: number, seed: number): string[]
```

Алгоритм:

```text
1. пул = слова той же части речи
2. фильтр по частоте: rank в диапазоне [rank/3, rank*3]
3. фильтр по уровню: ±1 ступень CEFR
4. ИСКЛЮЧИТЬ кандидатов, у которых пересекаются переводы с целевым
5. если кандидатов < n — последовательно ослаблять шаги 3, затем 2
6. выбрать n детерминированно по seed
```

**Шаг 4 обязателен и он неочевиден.** `znać` и `wiedzieć` оба переводятся «знать»:
без этого фильтра в вопросе окажется два правильных ответа. Проверять пересечение
по **полному множеству** переводов всех значений, а не по одному основному.

Шаг 5 нужен для редких слов: у C2 (всего 21 слово) соседей по уровню почти нет.

### 2. Морфологические дистракторы

```ts
pickFormDistractors(paradigm: Paradigm, targetSlot: Dimension, n: number, seed: number): string[]
```

Берутся **из той же парадигмы** — другие падежи/лица того же слова. Это и есть содержательная
сложность: пользователь выбирает между `kobiety / kobiecie / kobietą`, а не между разными словами.

Обязательно исключить формы, которые совпадают с правильным ответом: одна форма занимает
несколько слотов (`aborcji` = sg.gen, sg.dat, sg.loc) — иначе среди «неправильных» окажется верный.

Если в парадигме не набирается `n` различных форм — добить формами того же слота из парадигм
похожих слов той же части речи.

### 3. Детерминированность

Seed = хэш от `skillId + reps`. Один и тот же вопрос при ре-рендере даёт те же варианты;
при следующем повторении — другие.

### 4. Порядок вариантов

Позиция правильного ответа перемешивается тем же seed. Проверить, что правильный ответ
не оказывается систематически на одной позиции.

## Acceptance

- [ ] Дистракторы для `wiedzieć` не содержат `znać` и других слов с переводом «знать»
- [ ] Дистракторы для `mieć` — глаголы A1–A2 близкой частоты, не существительные C1
- [ ] Для слова уровня C2 генерация не падает и возвращает `n` вариантов
- [ ] `pickFormDistractors` для `aborcja` sg.gen не содержит `aborcji` среди неправильных
- [ ] Один seed → один и тот же набор и порядок
- [ ] Распределение позиции правильного ответа равномерно на 1000 генераций (χ²-тест или простая проверка разброса)
- [ ] Все ветви ослабления фильтров покрыты тестами
