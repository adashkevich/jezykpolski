## Требования: NFR-04, NFR-06, NFR-07, NFR-11, NFR-20

## Шаги

### 1. Доступность

Проход по всем экранам:

- [ ] все интерактивные элементы достижимы с клавиатуры, порядок фокуса логичен;
- [ ] видимый focus-ring везде, не отключён `outline: none` без замены;
- [ ] icon-only кнопки имеют `aria-label`;
- [ ] у полей ввода есть связанные `<label>`;
- [ ] верно/неверно различимо **без цвета** (иконка + текст);
- [ ] контраст ≥ 4.5:1 для текста в светлой и тёмной теме;
- [ ] `prefers-reduced-motion` отключает анимации переходов и свайпов;
- [ ] тач-таргеты ≥ 44px;
- [ ] у свайпов есть кнопочные эквиваленты (задача 16);
- [ ] правильная семантика: кнопки — `<button>`, ссылки — `<a>`, списки — списки;
- [ ] изменение состояния упражнения объявляется скринридеру (`aria-live` на области обратной связи).

Проверить `axe` на каждом основном экране.

### 2. E2E (Playwright, production-сборка)

Критический сценарий:

```text
1. открыть приложение
2. дождаться загрузки индекса
3. открыть список слов, применить фильтр «до A1»
4. запустить «Продолжить обучение»
5. ответить на 5 заданий (верно и неверно)
6. дойти до экрана результатов
7. перезагрузить браузер
8. проверить: прогресс на месте, счётчики главной обновились
9. открыть «Разобрать ошибки», пройти
10. проверить: SRS-состояние навыка НЕ улучшилось от повтора ошибки
```

Второй сценарий — данные:

```text
экспорт → сброс → импорт → прогресс идентичен
```

Третий — офлайн:

```text
загрузить → отключить сеть → перезагрузить → приложение открывается → сессия проходится
```

Тестировать **production-сборку**, не dev (blueprint §25): service worker в dev ведёт себя иначе.

### 3. Производительность

| Метрика | Цель | Как мерить |
|---|---|---|
| Холодный старт до интерактивности | ≤ 3 с | Lighthouse, throttled 4G + 4x CPU |
| Скролл списка 7998 слов | без пропущенных кадров | Performance-профиль, throttled 4x CPU |
| `queryWords` со всеми фильтрами | ≤ 16 мс | юнит-бенчмарк |
| Открытие `/stats` при 20 000 навыков | ≤ 300 мс | тест с синтетическими данными |
| Precache | ≤ 500 КБ gz | отчёт сборки |

Сгенерировать синтетический прогресс (20 000 навыков, 50 000 логов) фикстурой —
без него проблемы производительности не проявятся до продакшена.
