# 20 — Раздел глаголов и таблица спряжения

**Зависит от:** 17
**Результат:** режим «Глаголы» с прогрессом по временам.

---

## Требования: FR-03, FR-44, FR-47

## Данные

2501 глагол, 2499 парадигм, в среднем 29.2 формы (максимум 66).

| Признак | Покрытие |
|---|---|
| прошедшее время | 2499 / 2499 |
| будущее время | 2499 / 2499 |
| повелительное наклонение | 2498 / 2499 |
| смешанный аспект в одной парадигме | 84 глагола |

Измерения: `number`, `person` (1/2/3), `tense` (present/past/future), `mood`
(indicative/imperative/infinitive), `aspect` (imperfective/perfective), `gender`
(masculine_personal, non_masculine_personal, feminine, masculine, neuter), `analytic`.

**Три вещи, которые обязательно учесть:**

1. **Аналитические формы.** Будущее время несовершенного вида — составное:
   `będę robić`, `będziemy robić`, помечено `analytic: true`. Проверка ответа нормализует
   пробелы (задача 09), отображение помечает такие формы.
2. **Род в прошедшем времени.** `robiłem` / `robiłam` — разные формы одного лица.
   Навык обязан включать род: `verb:past:1:sg:masculine`, иначе упражнение неоднозначно (FR-66).
3. **Смешанный аспект.** У 84 глаголов в одной парадигме формы обоих видов.
   Не пытаться вывести один аспект на парадигму — хранить на уровне формы.

---

## Шаги

### 1. Прогресс по временам

```text
robić
делать

Значение       100%
Настоящее       85%
Прошедшее       60%
Будущее         20%
Повелительное   новое
```

### 2. Таблица спряжения

Вкладки по времени/наклонению. Внутри — `лицо × число`.
Для прошедшего времени добавляется измерение рода: либо третья ось, либо две колонки
(`mężczyzna` / `kobieta`) — второе проще и понятнее на мобильном.

Аналитические формы показываются целиком (`będziemy robić`), с визуальной пометкой составной формы.

### 3. Инфинитив

`mood: infinitive` — это сама лемма. Отдельным навыком не делать: он совпадает с
`vocab:pl-ru` и создаст ложную статистику.

### 4. Терминология

```text
czas teraźniejszy   (настоящее)
czas przeszły       (прошедшее)
czas przyszły       (будущее)
tryb rozkazujący    (повелительное)
```

Лица показывать местоимениями (`ja / ty / on · ona · ono / my / wy / oni · one`),
а не цифрами — так они и учатся.

### 5. Вне MVP

`tryb przypuszczający` (сослагательное) и `imiesłowy` (причастия) — если они есть в данных,
показывать в таблице, но не включать в тренировку по умолчанию (app-design §12).

## Acceptance

- [ ] Прогресс показывается раздельно по временам и наклонениям
- [ ] Таблица `robić` содержит present / past / future / imperative
- [ ] Аналитические формы отображаются целиком и помечены
- [ ] Прошедшее время показывает родовые варианты
- [ ] Навык прошедшего времени включает род в `skillId`
- [ ] Инфинитив не порождает отдельного морфологического навыка
- [ ] Глагол со смешанным аспектом отображается без потери форм
- [ ] Единственный глагол без imperative не ломает таблицу
- [ ] Лица подписаны местоимениями
