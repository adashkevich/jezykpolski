# 21 — Упражнения на формы глаголов

**Зависит от:** 20, 19
**Результат:** упражнения на спряжение.

---

## Требования: FR-64, FR-65, FR-66, FR-70

## Шаги

### 1. Одна форма от леммы

```text
robić

ty
czas teraźniejszy

[ robisz_____ ]
```

### 2. От перевода

```text
делать

my
czas teraźniejszy

[ robimy_____ ]
```

Тот же навык, другой `hintMode` — как у существительных (задача 18).

### 3. Прошедшее время — род обязателен (FR-66)

```text
robić

ja
mężczyzna
czas przeszły

[ robiłem ]
```

Без указания рода вопрос имеет два правильных ответа. Род — часть промпта и часть `skillId`.

### 4. Аналитические формы

```text
robić

my
czas przyszły

[ będziemy robić ]
```

Проверка нормализует пробелы. Опционально можно принимать и форму с инфинитивом,
и с l-причастием (`będziemy robili`), если обе есть в парадигме — тогда это два `accepted`
для одного слота.

### 5. Полная таблица спряжения

```text
robić · czas teraźniejszy

ja      [ robię   ]
ty      [         ]
on      [         ]
my      [         ]
wy      [         ]
oni     [         ]
```

Как и у существительных — **только Practice**, не в ежедневном SRS (задача 18, п.4).

### 6. Фильтры тренировки

Конфигурация для компонента настройки (задача 19):

```text
Время:  ☑ teraźniejszy  ☑ przeszły  ☐ przyszły
Лицо:   ☑ ja ☑ ty ☑ on/ona/ono ☑ my ☑ wy ☑ oni/one
Число:  ☑ singular ☑ plural
Позже:  ☐ tryb rozkazujący  ☐ tryb przypuszczający  ☐ imiesłowy
```

---

## Acceptance

- [ ] Упражнения работают для present / past / future / imperative
- [ ] Прошедшее время всегда указывает род в промпте
- [ ] `robiłem` не засчитывается за `robiłam` и наоборот
- [ ] Аналитическая форма принимается при любом количестве пробелов
- [ ] Оба варианта аналитической формы принимаются, если оба есть в парадигме
- [ ] `form-choice` берёт дистракторы из той же парадигмы (другие лица/времена)
- [ ] Таблица спряжения доступна только в Practice
- [ ] Фильтры времён и лиц влияют на очередь
