# 22 — Раздел прилагательных и степени сравнения

**Зависит от:** 20
**Результат:** режим «Прилагательные» с формами и степенями сравнения.

---

## Требования: FR-04, FR-45, FR-67, FR-68, FR-69

## Данные — здесь главная сложность

1400 прилагательных, 1400 парадигм, **в среднем 47.3 формы (максимум 140)** — больше всех.

Измерения: `number`, `case`, `gender`, `degree`.

**Поле `gender` у ADJ имеет девять значений, четыре из которых — агрегаты:**

```text
конкретные:  feminine · neuter · masculine · masculine_personal · masculine_inanimate
агрегаты:    any
             non_masculine_personal
             masculine_animate_or_personal
             masculine_or_neuter
```

Пример из данных (`absolutny`):

```text
adj:pl:dat:m1.m2.m3.f.n:pos   → gender: "any"
adj:pl:acc:m1:pos             → gender: "masculine_personal"
adj:pl:acc:m2.m3.f.n:pos      → gender: "non_masculine_personal"
```

Если показывать эти агрегаты в UI как есть, таблица `падеж × род` окажется неполной:
у ячейки `pl / dative / feminine` формы «нет», хотя на самом деле она покрыта записью `any`.

**Решение (задано в задаче 02, п.2):** единая раскладка агрегатов по конкретным родам,
объявленная один раз в `codec.ts` и переиспользуемая везде. UI не занимается этим сам.

```text
any                            → m1, m2, m3, f, n
non_masculine_personal         → m2, m3, f, n
masculine_animate_or_personal  → m1, m2
masculine_or_neuter            → m1, m2, m3, n
```

При обратном отображении (таблица) несколько родов, ведущих к одной форме, схлопываются
в объединённую ячейку — иначе таблица становится нечитаемой.

---

## Шаги

### 1. Навыки

`adj:<number>:<gender>:<case>` — по **конкретным** родам после раскладки агрегатов,
и только для слотов, реально покрытых парадигмой.

Плюс `adj:degree:comparative` и `adj:degree:superlative` для слов, у которых эти степени есть.

### 2. Таблица

Переключатель `singular / plural`, внутри — `падеж × род`:

```text
         m       f       n
M.       ...     ...     ...
D.       ...     ...     ...
```

Для мужского рода в singular различаются одушевлённость/личность там, где данные это различают
(`masculine_animate_or_personal` в accusative — классическая польская особенность).
Показывать это, а не прятать: это то, ради чего пользователь и учит формы.

### 3. Степени сравнения (FR-69)

```text
dobry

positive:      dobry
comparative:   [ lepszy ]
superlative:   [ najlepszy ]
```

Особенно ценно для нерегулярных (`dobry / lepszy / najlepszy`). Отдельный тип упражнения,
не смешивать с падежными.

Не у всех прилагательных есть степени сравнения — проверять наличие в парадигме.

### 4. Наречия (FR-05)

У ADV в данных только `degree` (411 парадигм, в среднем 2.1 формы).
Отдельного раздела не делать: степени сравнения наречий добавляются тем же компонентом,
что и для прилагательных.
