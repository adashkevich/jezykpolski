## Как пользоваться

1. Задачи идут по порядку номеров. Зависимости указаны в шапке каждой задачи.
2. Задача считается готовой, только когда выполнены **все** пункты её Acceptance.
3. После каждой задачи должно выполняться: `npm run build` без ошибок и `npm run lint` без ошибок.

## Журнал решений

Сюда записывай отклонения от `spec/architecture.md` и причины — правило blueprint §36.19.

| Дата | Задача | Решение | Причина |
|---|---|---|---|
| 2026-09-01 | 01 | Добавлен `@tanstack/react-virtual` (отклонение от blueprint §31) | Список из 7998 слов не бандлится целиком (requirements.md §4); собственная виртуализация с динамической высотой — источник багов скролла, библиотека headless и ~4 КБ gz |
| 2026-09-01 | 01 | `baseUrl` убран из `tsconfig.app.json`/`tsconfig.json`, остался только `paths: {"@/*": ["./src/*"]}` | В TypeScript 6.0 `baseUrl` deprecated (`TS5101`), ломает `tsc -b`; `paths` резолвятся относительно расположения tsconfig и без него |
| 2026-09-01 | 01 | `paths` продублирован в корневом `tsconfig.json` (solution-файл) | shadcn CLI читает корневой tsconfig напрямую и не подхватывает `paths` из `tsconfig.app.json`, иначе генерирует файлы в буквальный каталог `./@/...` |
| 2026-09-01 | 01 | `react-refresh/only-export-components` отключено только для `src/components/ui/**/*` | Сгенерированные shadcn-компоненты (напр. `button.tsx`) экспортируют не только компонент, но и `buttonVariants` — это vendor-код, не авторский |
| 2026-09-01 | 01 | Vitest ограничен `src/**`, из его области исключён `e2e/**` | Vitest по умолчанию подхватывал `e2e/*.spec.ts` и падал на Playwright-специфичном `test.skip`; раннеры несовместимы, разделены по каталогам |
| 2026-09-01 | 01 | `e2e/placeholder.spec.ts` содержит один `test.skip(...)`, а не пустая директория | Буквально пустой `e2e/` даёт `Error: No tests found` и exit code 1 у Playwright; плейсхолдер даёт exit code 0 без реальных сценариев (появятся в задаче 26) |
| 2026-09-01 | 01 | `src/index.css` (стили шаблона Vite) удалён, а не оставлен рядом с `globals.css` | Содержал хардкод шаблона (`#root { width: 1126px }`), нарушал acceptance «не осталось файлов стартового шаблона» и запрет page-specific CSS (blueprint §8) |
| 2026-09-01 | 01 | `src/App.tsx` остался на месте (не перенесён в `src/app/App.tsx`) | Задача 01 требует только очистить содержимое; полноценный AppShell/роутинг по структуре `architecture.md §3` — предмет задачи 06 |
