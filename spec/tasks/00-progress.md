## Как пользоваться

1. Задачи идут по порядку номеров. Зависимости указаны в шапке каждой задачи.
2. Задача считается готовой, только когда выполнены **все** пункты её Acceptance.
3. После каждой задачи должно выполняться: `npm run build` без ошибок и `npm run lint` без ошибок.
