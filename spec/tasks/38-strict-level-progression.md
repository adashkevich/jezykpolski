# 38 — Строго последовательное прохождение уровней

**Зависит от:** 35
**Результат:** новые слова ежедневной сессии всегда берутся ровно из одного уровня — младшего
из открытых, в котором ещё остались неначатые слова. Следующий уровень открывается только
когда у текущего не осталось ни одного неначатого слова — ни раньше по порогу, ни по факту
ручного начала слова выше по уровню.

---

## Требования: FR-143, FR-146 (изменены), FR-144 (отменено)

## Зачем

Воротник задачи 35 решал задачу «не выдавать C1 новичку в первую неделю», но внутри себя
держал два послабления, оба ради того, чтобы не «застревать» на одном уровне:

1. `LEVEL_UNLOCK_REMAINING = 50` — следующий уровень открывался, когда в текущем оставалось
   ≤ 50 неначатых слов, то есть примерно за 5 дней (при бюджете 10 новых слов в день) до
   фактического конца уровня.
2. Храповик `startedByLevel[L+1]` — одно слово следующего уровня, начатое вручную кнопкой
   «Учить» с карточки слова, открывало весь уровень навсегда, даже если текущий ещё далеко не
   пройден.
3. `orderNewWordCandidates` мешала два младших открытых уровня в пропорции 2:1 — то есть
   треть новых слов всё равно шла со следующего уровня, ещё до того как текущий кончался.

Прямое решение пользователя: убрать оба послабления. Следующий уровень не должен появляться
ни при каких условиях, пока в текущем остаётся хоть одно слово, у которого нет ни одной записи
навыка — «все слова хотя бы в обучении».

Размер корпуса по уровням (`public/content/index.json`): A1 386, A2 1116, B1 2401, B2 3141,
C1 933, C2 21. При дефолтных 10 новых словах в день A1 занимает ~39 дней вместо ~34 у задачи 35
— цена строгости небольшая, а порядок прохождения предсказуем: пользователь всегда точно
знает, какой уровень изучает.

---

## 1. `learning/session/level-gate.ts`

`unlockedLevels` — правило 3 задачи 35 схлопнуто до одного условия:
`unstartedByLevel[L] === 0`. `LEVEL_UNLOCK_REMAINING` и `LevelPoolCounts.startedByLevel`
удалены — храповику больше не на чем работать.

Новый экспорт:

```ts
/** Младший из открытых уровней, в котором ещё есть неначатые слова — тот единственный
 *  уровень, из которого сессия сейчас реально берёт новые слова. `undefined`, если весь
 *  открытый диапазон пройден. */
export function currentNewWordLevel(
  counts: LevelPoolCounts,
  startLevel: LevelValue,
): LevelValue | undefined
```

Одна точка правды и для `session-scope.ts`, и для `useLevelGate.ts` — оба места раньше сами
выводили бы «текущий уровень» из `unlocked[0]`, дублируя одно и то же решение.

`orderNewWordCandidates` — цикл `L0, L0, L1` заменён на сортировку по `(индекс уровня в
LEVEL_VALUES, rank)`. Под новым правилом неначатые слова есть только у одного уровня разом
(иначе следующий не открылся бы), так что смешивать больше нечего — но сортировка не
полагается на этот инвариант, а обеспечивает его структурно.

## 2. `db/repositories/words-progress.repository.ts#computeLevelPoolCounts`

Перестаёт заполнять `startedByLevel` — тот же единственный проход по
`getIndexStore().byLevel`, считающий только `unstartedByLevel`.

## 3. `hooks/useLevelGate.ts`

`LevelGateState` получает `currentLevel: LevelValue | undefined` из `currentNewWordLevel`.
`unlocked` остаётся (нужен `/stats`, см. ниже).

## 4. `pages/home/HomePage.tsx`

Строка под кнопкой «Продолжить обучение» строится по `currentLevel`, а не по
`unlocked.join(' + ')`: под новым правилом `unlocked` — это «все пройденные уровни + текущий»,
и печатать список привело бы к растущей со временем строке «A1 + A2 + B1 + …», хотя новые
слова всегда идут только с последнего. Строка скрывается ровно когда `currentLevel ===
undefined` (весь открытый диапазон пройден — это существующее состояние «нет новых слов»,
не новый пустой экран).

## 5. `pages/stats/StatsPage.tsx` — без изменений в коде

`levelGate.unlocked` теперь буквально «пройденные + текущий», поэтому «откроется позже» на
уровнях выше текущего работает без правок.

---

## Где ничего не меняется

- `session-scope.ts#resolveGlobalScope` — вызывает `unlockedLevels`/`orderNewWordCandidates`
  с теми же сигнатурами.
- `resolveFilterScope`, Practice — воротник туда по-прежнему не дотягивается (задача 35 §2).
- Повторения по расписанию — воротник фильтрует только новые слова; слово выше текущего
  уровня, начатое вручную, продолжает приходить на повторение как обычно.

## Acceptance

- [ ] Следующий уровень не появляется в новых словах ни при каких условиях, пока в текущем
      остаётся хоть одно слово со статусом `new`
- [ ] Слово, начатое вручную выше текущего уровня («Учить» с карточки слова), само по себе
      следующий уровень не открывает
- [ ] Как только последнее слово текущего уровня начато, новые слова следующей же сессии идут
      с уровня выше — без «переходного» смешивания
- [ ] Главный экран показывает ровно один уровень («Сейчас изучаем: A1 · осталось N слов»), не
      список
- [ ] `/stats` по-прежнему помечает пройденные уровни как открытые, а более высокие — «откроется
      позже»
- [ ] `npm test`, `npm run lint`, `npx tsc -b` проходят
