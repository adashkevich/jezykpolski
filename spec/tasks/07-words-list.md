# 07 — Список слов

**Зависит от:** 04, 05, 06
**Результат:** экран `/words` — браузер по 7998 словам с фильтрами, поиском, сортировкой и виртуализацией.

---

## Требования: FR-20 … FR-30

## Шаги

### 1. Виртуализация

7998 строк. Без виртуализации мобильный скролл проседает (NFR-07).
`@tanstack/react-virtual`, фиксированная высота строки (проще и быстрее динамической).
Обоснование библиотеки — `requirements.md` §4.

### 2. Строка списка

```text
być
быть
VERB · A1 · #1                    [индикатор статуса]
```

Статус показывается **не только цветом** (NFR-11): цвет + иконка/подпись.
Состояния: `Новое / Изучаю / Знаю / Освоено`.

### 3. Панель фильтров

Уровень — чипы с множественным выбором `A1 A2 B1 B2 C1 C2`.
Отдельный переключатель режима **«До уровня X»** (FR-22, основной сценарий пользователя):
включён — выбор одного уровня означает все уровни до него включительно.

Часть речи, статус, частотность, сортировка — селекты. На мобильном раскрываются в
шторке (shadcn `Drawer`/`Sheet`), а не в выпадающем меню.

Показывать число найденных: `Найдено 3 903`.

### 4. Поиск

Одно поле, ищет и по польской лемме, и по русскому переводу (FR-27).
Debounce 200 мс. Диакритики нормализуются (`zolty` → `żółty`).

### 5. Переключатель части речи как вход в разделы

Вкладки над списком: `Все · Сущ. · Глаголы · Прил. · Наречия`.
Выбор части речи меняет режим отображения строки: для NOUN/VERB/ADJ в строке появляется
**вторая шкала прогресса — «Формы»** (FR-46, app-design §8). Это и есть «разделы»
из app-design, без дублирования экранов.

### 6. Прогресс в строке

Нужна `Map<WordId, WordProgressRecord>` для 7998 слов. Загружать её **один раз** через
`useLiveQuery` и держать в памяти, не запрашивать на каждую строку.

### 7. Кнопка «Учить»

Плавающая кнопка на экране открывает настройку сессии (задача 19) с предзаполненными
текущими фильтрами. В MVP до задачи 19 — сразу запускает Learn-сессию по текущему фильтру.

### 8. Сохранение состояния фильтров

Zustand + persist в `settings` (FR-30). Восстанавливать позицию скролла при возврате
с карточки слова — иначе браузер по 8000 слов невозможно использовать.
