# 18 — Упражнения на формы существительных

**Зависит от:** 17
**Результат:** типы упражнений `form-input`, `form-choice`, `table` для существительных.

---

## Требования: FR-60, FR-61, FR-62, FR-70, FR-93

## Шаги

### 1. Вариант A — от польской леммы (FR-60)

```text
kobieta

Dopełniacz
liczba pojedyncza

[ kobiety_____ ]
```

### 2. Вариант B — от русского перевода (FR-61)

```text
женщина

Narzędnik
liczba mnoga

[ kobietami_____ ]
```

Сложнее: нужно сначала вспомнить лемму, потом просклонять. Это **тот же навык**,
но с другой подсказкой — не отдельный skillId, а параметр `hintMode` упражнения.

Настройка подсказки (app-design §9): `показать польскую лемму / показать русский перевод / случайно`.

### 3. Вариант с выбором (FR-70)

`form-choice` — 4 формы из той же парадигмы (задача 10, `pickFormDistractors`).
Используется на ранних стадиях навыка, до перехода на ввод (задача 09, picker).

### 4. Вариант C — таблица (FR-62)

```text
kobieta
             sg           pl
M.           kobieta      kobiety
D.           [       ]    [       ]
C.           [       ]    [       ]
...
```

**Только режим Practice/Drill, не в ежедневном SRS.** Причина (app-design §10):
таблица — это 12+ ответов подряд по одному слову; в SRS-очереди это ломает интервальное
распределение и утомляет. В таблице заполненная ячейка обновляет соответствующий навык,
но с демпфированием practice-режима (задача 11, правило 2).

Первая строка (Mianownik) предзаполнена как опора.

### 5. Проверка ответа

Через `grade` (задача 09). Критично:

- слот принимает **все** валидные формы (`aborcji` и `aborcyj` для sg.gen);
- ответ без диакритик → `nearMiss`, не «верно» и не «неверно».

### 6. Отображение слота

Польское название падежа + польское название числа (`Dopełniacz`, `liczba pojedyncza`),
русское — мелким шрифтом. Согласовано с задачей 17, п.5.
