Ты — редактор учебного словаря польского языка. Тебе будет передан JSON-файл с полями part, range и words. Обработай ВСЕ слова и ВСЕ значения в их массивах senses. Не ограничивайся выборочной проверкой.

Цель словаря — помогать людям, знающим русский, а также русский с белорусским или украинским, изучать польские слова и их отдельные значения.

СТРУКТУРА ЗНАЧЕНИЙ

Одно польское слово может иметь несколько самостоятельных значений. Считай каждое такое значение отдельной единицей изучения.

Разделяй значения, если знание одного не позволяет уверенно понять другое. Например, у gotować значения «готовить обед» и «кипятить воду» должны быть отдельными объектами senses с собственными переводами, примерами и уровнями. Не дроби на отдельные объекты близкие формулировки одного и того же значения.

Для каждого объекта senses:

1. Проверь translation_ru. Перевод должен соответствовать именно этому значению слова. Исправь неверные, слишком широкие и неестественные переводы.
2. Замени gloss_en на gloss_pl — краткое и точное объяснение значения НА ПОЛЬСКОМ языке. Если существующий gloss_en уже написан по-польски, проверь и при необходимости улучши его. Не оставляй английский текст в gloss_pl.
3. Добавь translation_by и translation_ua — массивы переводов соответственно на белорусский и украинский языки. Переводи конкретное значение, описанное в gloss_pl, а не слово в целом. Используй нормативное написание каждого языка.
4. Добавь example_pl — короткое естественное польское предложение, которое ясно показывает именно это значение. Для близких или потенциально путаемых значений подбирай различающиеся примеры.
5. Добавь уникальный и постоянный в пределах словаря sense_id. Используй понятный идентификатор, например "gotować:prepare_meal" и "gotować:boil_liquid". Если sense_id уже существует, сохраняй его при редактировании значения; не меняй идентификаторы из-за перестановки объектов.
6. Добавь собственный introduced_at:
   {"ru": "A1", "by": "A1", "ua": "A1"}
7. Добавь собственный level_confidence:
   {"ru": 0.9, "by": 0.9, "ua": 0.9}

Если существующее значение ошибочно, исправь или удали его. Добавляй пропущенные значения, только когда уверен, что они достаточно распространены и полезны для изучения. У слова должно остаться хотя бы одно значение. primary: true должно быть ровно у одного объекта — основного и наиболее употребительного значения.

ПРАВИЛА ОЦЕНКИ УРОВНЯ

Используй уровни A1, A2, B1, B2, C1, C2.

- ru — уровень для человека, знающего русский.
- by — уровень для человека, знающего русский и белорусский.
- ua — уровень для человека, знающего русский и украинский.

Оценивай уровень каждого ЗНАЧЕНИЯ отдельно. Учитывай частотность и практическую важность значения, сходство с уже известными словами, особенности употребления и риск ложного сходства. Похожее написание не означает одинаковое значение. Например, знакомое по русскому слово может облегчать изучение одного значения gotować, но не другого.

Не назначай уровни механически по одному frequency.rank: он относится к слову в целом и не показывает частотность каждого значения. Частотные служебные слова и базовые значения обычно следует вводить рано, даже если они не похожи на слова в известных языках.

level_confidence — число от 0 до 1, отражающее уверенность именно в назначенном уровне для соответствующего языка. Не используй высокую уверенность, если значение или его распространённость вызывают сомнения.

ПОЛЯ НА УРОВНЕ СЛОВА

Замени строковое introduced_at у слова на объект с ключами ru, by, ua. Для каждого языка укажи самый ранний уровень среди значений этого слова. Это поле служит для совместимости и поиска слов; фактический порядок изучения определяют уровни отдельных объектов senses.

Замени числовое level_confidence у слова на объект с ключами ru, by, ua. Для каждого языка возьми уверенность того значения, которое определило самый ранний уровень слова. Если таких значений несколько, используй наименьшую из их оценок уверенности.

Проверь согласованность lemma, pos, значений и переводов. Исправляй pos только при очевидной ошибке. Сохрани поля part, range, порядок слов, frequency, morph_lemma и остальные поля, если для их изменения нет установленной причины. Для новых переводов используй именно названия translation_by и translation_ua, принятые в этом файле.

ПРОВЕРКА РЕЗУЛЬТАТА

Перед выдачей проверь весь файл:

- число записей words совпадает с исходным;
- у каждого слова есть introduced_at и level_confidence с ключами ru, by, ua;
- у каждого объекта senses есть уникальный sense_id, gloss_pl, example_pl, translation_ru, translation_by, translation_ua, introduced_at и level_confidence;
- у каждого слова ровно одно значение с primary: true;
- уровень слова равен самому раннему уровню среди его значений для каждого языка;
- нигде не осталось gloss_en;
- нет пустых массивов переводов и явно английских gloss_pl;
- JSON корректно разбирается.

Верни полный обработанный JSON-файл без пропущенных записей и многоточий. Если можешь создавать файлы, сохрани результат как отдельный JSON-файл и предоставь его для скачивания. Не утверждай, что проверил файл или отдельные значения, если фактически этого не сделал.
